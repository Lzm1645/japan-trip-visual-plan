# 日本七日旅行计划｜东京 · 大阪 · 京都

> 旅行日期：2026 年 9 月 30 日（周三）—10 月 6 日（周二）
>
> 行程天数：7 天 6 晚
>
> 住宿分配：东京 3 晚、大阪 2 晚、京都 1 晚
>
> 进出机场：成田机场 T1 入境、关西机场 T1 离境
>
> 在线视觉版：[lzm1645.github.io/japan-trip-visual-plan](https://lzm1645.github.io/japan-trip-visual-plan/)

这份文档以此前 ChatGPT 会话中确定的高评分方案为准。整体原则不是堆景点，而是每天保留：

> **1 个主区域 + 1 项特色体验 + 1 顿重点餐 + 1 段自由夜生活**

路线为东京、大阪、京都，重点保留新干线看富士山、USJ 万圣节夜场、大阪泡汤、京都町屋、东山夜游与清晨伏见稻荷。

## 每日详细计划

### Day 1｜9 月 30 日（周三）：抵达东京，浅草夜生活

14:00 抵达成田机场 T1。完成入境和取行李后，预计 15:30–16:00 离开机场。优先查看前往押上、浅草方向的 Access 特急，预计 17:00–18:00 抵达吾妻桥民宿。

晚间路线：

> 民宿 → 吾妻桥 → 隅田川 → 雷门 → 浅草寺夜景 → 传法院通 → 晚餐

第一晚不去新宿，也不赶正式景点。晚餐首选浅草鳗鱼饭，其次是江户天丼或当地烧鸟居酒屋。当天不锁定昂贵且严格计时的预约餐，避免航班或入境延误打乱安排。饭后逛便利店，购买第二天的饮料、早餐备选与常用物品。

### Day 2｜10 月 1 日（周四）：浅草、上野与秋叶原

| 时间 | 安排 |
|---|---|
| 07:30 | 日式早餐：味噌汤、饭团、烤鱼或玉子烧定食 |
| 08:30 | 雷门 → 仲见世 → 浅草寺 → 浅草神社；购买御朱印帐 |
| 10:30 | 上野博物馆二选一，首选东京国立博物馆，预留 2–2.5 小时 |
| 13:30 | 上野寿司、海鲜丼或普通吧台午市 |
| 15:00 | Radio Kaikan → 电器街 → 动漫店 → 游戏厅或扭蛋 |
| 19:00 | 上野或浅草居酒屋：刺身、烧鸟、炸物与清酒或梅酒 |

秋叶原景点部分控制在约 2 小时，另留 45–60 分钟体验音游、抓娃娃、扭蛋或二手游戏与手办店。晚上不再安排观景台。

### Day 3｜10 月 2 日（周五）：明治神宫、涩谷与和牛

| 时间 | 安排 |
|---|---|
| 08:30 | 明治神宫清晨参拜，可收第二枚御朱印 |
| 10:30 | 原宿 → Cat Street → 表参道外围 → 涩谷 |
| 12:30 | 日式定食、炸猪排或牛舌午餐 |
| 14:00 | 涩谷 PARCO：Nintendo TOKYO、Pokémon Center、Jump Shop 等 |
| 16:30–17:00 | Shibuya Sky，预约日落前 30–60 分钟的时段 |
| 19:00 | 涩谷站步行范围内的和牛烧肉 |

竹下通只简单经过，不为网红甜品长时间排队。当天保留一次咖啡馆休息，Shibuya Sky 是全程唯一的收费城市观景台。

### Day 4｜10 月 3 日（周六）：新干线看富士山，大阪夜食

上午慢节奏退房，不加入 teamLab、东京塔或六本木。

> 退房 → 东京站丸之内外观 → KITTE 附近 → 地下食品街

在东京站购买新干线便当、饮料、季节甜点和伴手礼。13:00–13:30 搭乘东京至新大阪的新干线，普通车厢选择 D、E 两个连座，E 为窗边，用于观看富士山；如有特大行李，应选择带对应放置区的座位。

约 16:30 入住大阪，18:00 首选味乃家本店大阪烧，可购买 FastPass，但它只是优先排队。晚间按以下路线散步：

> 法善寺横丁 → 道顿堀 → 戎桥 → 心斋桥

途中两人分食一份章鱼烧。可加入 30–45 分钟游戏厅或立饮店，不再安排观景台。

### Day 5｜10 月 4 日（周日）：USJ 完整体验日

这天即使是周日也保留给 USJ，因为可以从开园玩到夜间活动结束，不用拖行李，也不会牺牲京都唯一的下午和晚上。

建议购买：

> **Studio Pass + 包含超级任天堂世界指定时段的 Express Pass 4 或 7**

项目优先级：

1. 咚奇刚疯狂矿车
2. 马力欧赛车
3. 超级任天堂世界自由探索
4. 哈利·波特禁忌之旅
5. 飞天翼龙或好莱坞美梦二选一
6. 大白鲨
7. 当期限定项目

早餐在便利店解决。园内只安排一顿完整主题餐，可选奇诺比奥咖啡店或三把扫帚；另一顿吃万圣节限定小吃。一定留到夜间，不要在 18:00 前离场。具体活动日期、开园时间和项目运行状态需在出发前以 USJ 官方信息为准。

### Day 6｜10 月 5 日（周一）：大阪泡汤，下午进入京都

| 时间 | 安排 |
|---|---|
| 08:00 | 大阪退房并寄存行李；住宿不能寄存时使用难波或日本桥车站行李柜 |
| 08:45–10:30 | SPA WORLD，只安排温泉和桑拿，不玩泳池和滑梯 |
| 10:45 | 新世界串炸早午餐，不要吃得过饱 |
| 12:15–12:30 | 取行李后前往京都，争取 14:00 左右抵达住处 |
| 14:30 | 出发前往清水寺，优先考虑出租车至五条坂或清水道附近 |
| 15:00–16:15 | 清水寺；必须先参拜，再逛二年坂、三年坂 |
| 16:15–18:00 | 三年坂 → 二年坂 → 八坂塔 → 石塀小路外围；中途一次抹茶休息 |
| 18:00–19:15 | 八坂神社 → 祇园白川 → 鸭川 |
| 19:30 | 京都纪念餐，优先季节京料理，也可改为おばんざい或豆腐料理 |

当天的硬规则是最晚 10:30 离开 SPA WORLD；一旦延误，缩短泡汤时间，不能牺牲清水寺。晚餐后返回町屋或别墅住宿，不再外出。

### Day 7｜10 月 6 日（周二）：伏见稻荷清晨，前往机场

| 时间 | 安排 |
|---|---|
| 06:30 | 伏见稻荷大社 → 千本鸟居 → 奥社奉拜所 → 原路返回 |
| 09:00 | 住处附近吃日式早餐并整理行李 |
| 10:00 | 退房，前往京都站 |
| 10:30–11:15 | 购买京都和果子、抹茶伴手礼、鲭鱼寿司或便当与饮料 |
| 11:15–11:30 | 搭乘能在 12:40–13:00 抵达关西机场 T1 的 HARUKA |
| 16:45 | 航班起飞 |

伏见稻荷游览控制在约 1.5 小时，不登稻荷山山顶。HARUKA 不锁死某一班，但目标是在起飞前接近 4 小时抵达机场。

## 使用说明

- 本 README 是完整文字计划；[在线视觉版](https://lzm1645.github.io/japan-trip-visual-plan/)用于快速查看每天的路线和真实地点照片。
- 时间均为规划值，应根据航班、天气、人流、预约结果和交通运行情况动态调整。
- 开放时间、票价、列车时刻与活动规则可能变化，出发前以各机构官方公告为准。
- 视觉版中的地点图片来自网络实景摄影，不使用 AI 生成的地点图片；来源记录见 [`photo-sources.md`](./photo-sources.md)。

## 项目开发与部署

项目使用 React 和 Vite 构建，通过 GitHub Actions 自动发布到 GitHub Pages。

```bash
pnpm install
pnpm dev
```
