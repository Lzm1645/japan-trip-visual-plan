## 目前最重要的调整

1. **首晚已不适合排浅草寺。** 银座和牛曾订在 18:00，距 14:00 成田落地只有 4 小时，还要入境、取行李和进城。应先核对预订是否已经改晚；若仍为 18:00，就按“机场直达银座、寄存行李、用餐后入住吾妻桥”准备，并与餐厅确认迟到处理。成田机场官方列有[开往银座的机场巴士](https://www.narita-airport.jp/en/access/bus/leaving-the-airport/)和[铁路选项](https://www.narita-airport.jp/en/access/train/)，当天应按航班与交通实时情况选择。
2. **秋叶原移到 10/2 上午。** 10/1 已约 11:45 浅草海鲜丼，下午再去上野，晚间想逛银座并去 Lupin；把秋叶原塞在中间会挤掉吃饭和购物时间。
3. **10/2 围绕 12:30 鳗鱼饭走。** 上午秋叶原只逛目标店；午餐后去涩谷 PARCO、十字路口和 Shibuya Sky。明治神宫、原宿变为有余力时的替换项。群聊后来已取消东京的大阪烧预订，不再显示为当晚计划。
4. **10/3 晚餐改为已约的京都居酒屋。** 清水寺和二三年坂安排在晚餐前，时间不足时删掉祇园的额外绕路，不压缩 19:00 预订。
5. **10/5 大阪烧不是硬性晚餐。** 同行希望四人一起吃，但目标热门店不接受预约。USJ 万圣节夜场优先；若离园晚或排队过长，改吃营业较晚的其他餐食。不要为了排队提前结束乐园。

## 每日安排

### Day 1｜9/30：成田入境与银座和牛

- 14:00 抵达成田 T1；入境、行李和换乘时间留弹性。
- 核对银座和牛的最终订单。若仍是 18:00，直达银座并提前确认能否寄存行李；不要先绕去吾妻桥。若已改至 19:30 或更晚，可考虑先去民宿放行李。
- 晚餐后前往吾妻桥入住。隅田川或浅草夜景仅作为体力允许时的加项，不设必须完成的打卡点。

**关键风险：** 18:00 的预订没有航班延误余量。预约人应尽快核对晚到、改时和取消规则。

### Day 2｜10/1：浅草、上野与银座

| 时间 | 安排 |
|---|---|
| 08:30 左右 | 雷门、浅草寺与仲见世；可收御朱印 |
| 11:45 | 已约浅草海鲜丼，按订单地址提前到店 |
| 13:30 左右 | 上野博物馆选一个馆，约 2 小时 |
| 17:00 起 | 银座购物，晚餐灵活处理，之后去 Bar Lupin |

银座购物只选一组主线，例如三越与 GINZA SIX，或三丽鸥、Loft 和 UNIQLO。Bar Lupin 留作当晚重点，但需提前核对营业、支付、席位与拍摄规则；酒吧排队太长时，不牺牲第二天的休息。

### Day 3｜10/2：秋叶原、鳗鱼饭与涩谷

- 秋叶原商店上午较晚开门，先确定想逛的 1–2 家，不安排完整“扫楼”。买了大件再决定寄存，避免为放行李反复穿城。
- **12:30 银座鳗鱼饭已约。** 从秋叶原出发留足交通时间；改约或取消期限以订单为准。
- 下午去涩谷 PARCO、角色商店与十字路口。Shibuya Sky 若买到合适时段票，再安排日落前入场；若未买到，就把时间留给购物与咖啡。
- 原计划的明治神宫和原宿可以作为替换，不再与三个购物片区叠加。晚餐尚未定，不再写成已约和牛或大阪烧。

### Day 4｜10/3：东京至京都

- 建议上午从东京站乘东海道新干线到京都，在车上吃车站便当。普通车厢东京至京都方向，想看富士山可优先选 E 座靠窗；是否看见取决于天气。
- 抵达后放行李，先去清水寺，再沿三年坂、二年坂和八坂塔慢走。若时间充裕，可延伸到八坂神社或祇园。
- **19:00 京都居酒屋已约。** 到店地址、人数和取消规则须核对预订确认页；晚餐后回京都住宿。
- 大件行李可考虑从东京寄往大阪，京都只带一晚用品，但务必先确认两家住宿是否接收与寄送时效。

### Day 5｜10/4：京都清晨与大阪泡汤

- 清晨去伏见稻荷，走千本鸟居到奥社附近即可。若前夜休息不足，改为慢早餐或住宿附近散步。
- 中午前后前往大阪高津民宿，下午按体力选新世界串炸与 SPA WORLD。泡汤不应早于设施实际开门；入场、纹身与维护规则临近再看[官方页面](https://www.spaworld.co.jp/)。
- 晚上去道顿堀散步和吃饭。原本想约的 17:30 大阪烧会让京都转场太赶，群聊已决定不强追那家。

### Day 6｜10/5：USJ 与万圣节夜场

- 整天留给 USJ，不搬行李。以当天官方营业时间安排进园；任天堂区域和快速票时段以实际购票内容为准。
- 留出主题餐与万圣节夜间内容，不为刷满项目或吃晚餐而过早离园。
- 群聊希望与另一位同行者在大阪吃大阪烧，但目前讨论的热门店**不能预约**。如果夜场结束后仍有营业、排队可接受，再把它当作加项；否则换更灵活的夜宵。

### Day 7｜10/6：难波收尾，关西机场返程

- USJ 后睡足，在难波吃早餐、补齐伴手礼，取行李后去南海难波站。
- 目标约 13:00 到关西机场 T1，为 16:45 的国际航班留足值机、安检和出境时间。Rapi:t 或机场急行选当天合适班次，不在上午加入远距离景点。
